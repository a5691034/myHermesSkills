
# Hermes Agent 使用过程中发现的问题以及处理方案

## 一、你发消息时如果 Profile正在执行，新消息会排队（queue），等当前这轮跑完再处理你的新消息。

### 方案一：用 `/stop` 强制中断（推荐）

在 Hermes Studio 的聊天框里直接输入：

```
/stop
```

这会立即**杀死当前正在执行的所有后台进程**，然后你就可以发新消息了。

### 方案二：用 `/busy interrupt` 改变默认行为

在 Hermes Studio 或 CLI 中设置：

```
/busy interrupt
```

这个命令有三个模式：

| 模式 | 行为 | 适用场景 |
|------|------|---------|
| `queue`（默认） | 新消息排队，等当前跑完再处理 | 不想打断当前任务 |
| **`interrupt`** | **收到新消息直接中断当前任务，立即处理** | 发现错误要立即纠正 |
| `steer` | 在当前工具调用完成后插入你的消息，不中断 | 轻微调整方向 |

设置后，你发新消息时，Hermes 会**立即中断当前执行**，处理你的新消息。

### 方案三：用 `/steer` 做中途纠正

如果不想完全中断，只是想纠正方向：

```
/steer 刚才那个方向不对，应该用暖色调
```

这会在当前工具调用完成后插入你的指令，不中断整个流程。

**总结：你只需要记住 `/stop` 和 `/busy interrupt` 这两个命令，前者是"紧急刹车"，后者是"改默认行为"。**

## 二、给Profile定一个工作流程

```
sould.md
alias: 车身广告设计师
role: 公交车车身广告设计专家
---

## 工作原则

### 第一步：出方案，不执行
每次收到任务后，先输出一个**方案计划**，不要直接执行。
方案内容至少包括：
1. 理解到的需求要点
2. 推荐的工作步骤
3. 备选方案（如有）

### 第二步：等待用户确认
方案展示后，等待用户确认或提出修改意见。
在获得明确确认之前，**不进行任何实质操作**。

### 第三步：遇到不确定时，主动提问
当方向不明确时，使用clarify工具让用户选择。
让用户输入文本时，要有输入框。
```
