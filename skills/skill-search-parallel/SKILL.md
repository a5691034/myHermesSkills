# 并行技能搜索

当用户提出"找技能"、"搜技能"、"推荐技能"、"有没有 X 功能"等需求时，**同时并行**派出子 Agent 从多个平台搜索，汇总后反馈。

## 核心流程

### Step 1：理解需求

从用户自然语言中提取：
- **任务意图**（用户想要做什么）
- **领域关键词**（中英文同义词，2-4 个）
- **搜索意图**（找技能 vs 问功能 vs 确认有无）

### Step 2：并行搜索

使用 `delegate_task` 同时派出多个子 Agent，**不要串行执行**：

```python
delegate_task(
    tasks=[
        {
            "goal": "在 SkillHub 上搜索与「{关键词}」相关的技能。使用 find-skill-skillhub 技能，遵循其五步流程。搜索关键词包括：{关键词列表}。返回格式：每条给出 名称、一句用途、匹配理由、下载量、安装量。",
            "context": "你是技能搜索专家。用户需要找关于「{关键词}」的技能。请从 https://skillhub.cn 搜索。",
        },
        {
            "goal": "在 skills.sh 上搜索与「{关键词}」相关的技能。使用 @vercel-labs/find-skills 或 find-skills 技能，运行 npx skills find {query} 搜索。返回格式：每条给出 名称、用途描述、安装量、来源（owner/repo）、安装命令。",
            "context": "你是技能搜索专家。用户需要找关于「{关键词}」的技能。请从 https://skills.sh 搜索。",
        },
    ],
    background=True,
)
```

### Step 3：汇总去重

收到所有子 Agent 返回后：
- 按平台分组
- 按契合度/热度排序
- 去重（同一功能可能有不同平台同名技能）

### Step 4：输出格式

```
🔍 为你找到 {N} 个相关技能（{M} 个平台）

┌─ SkillHub（中文）───────────────────────────┐
1. {name} — {一句话用途}
   匹配理由：{为什么适合}
   下载：{downloads} | 主页：{url}

┌─ skills.sh（全球）─────────────────────────┐
1. {name} — {用途描述}
   安装量：{count} | 来源：{owner/repo}
   安装命令：npx skills add {package}
```

### Step 5：等待用户选择

让用户选择安装哪个，或要求换词再搜。

## 注意事项

- **必须并行**，不要串行搜索（浪费时间）
- 每个子 Agent 用独立上下文，带上完整搜索关键词
- 子 Agent 用各自平台的原生命令/工具，不要跨平台
- 汇总时保留匹配理由，不要只扔链接
- 如果搜索结果为空，换同义词/上位词重试一次
- 推荐不超过 3-5 个，太多让用户选不出来
